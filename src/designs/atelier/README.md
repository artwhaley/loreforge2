# Atelier

Lab-first visual implementation. Registered with all 16 required page slots plus the optional character profile, its own shell, CSS, versioned configuration, Studio editor, and thumbnail. No imports from another Design.

## Review

Run `npm run design:discover`, then `npm run dev -- --port 4175` from the design-lab directory. Choose **Atelier** in the Design selector. Use the Lab's surfaces, scenario, Studio, viewport, and comparison controls to review it beside Obsidian.

## Deliberately deferred

Per the user's direction, this delivery prioritizes the rendered website over integration against the changing parity contract. The manifest's first-class label identifies the intended Design registration, not certification of full behavioral or production parity.

- Records search, folder selection, and sorting operate locally on the supplied preview records; reconnect the shared records workspace after freeze for server search, pagination, supersession, and mutation actions.
- Members filtering and role/type selection work locally. Management mutations, remote people search, access editing, invitations, and work decisions await connection. A preview note marks those unfinished operational surfaces; no fake successful saves are shown.
- Document action props are rendered through the shared presentation helper; end-to-end action behavior is not certified.
- Production installation and folder-parity certification have not been performed.

Verification at delivery: Design discovery and TypeScript/Vite build pass; Atelier home visually inspected in the running Lab. Do not interpret this as an exhaustive interaction or responsive test report.
