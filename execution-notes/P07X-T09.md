# P07X-T09 — Domain invitation workflows

Status: complete

## What shipped

- Added access-closed bootstrap and Domain join request collections with
  immutable targets and invitation-purpose checks.
- Added explicit platform bootstrap, Character claim, and Domain join service
  workflows. Acceptance and approval decisions join invitation consumption,
  ownership, identity provisioning, membership, and audit-relevant state in
  the same SQLite transaction.
- Added purpose-specific authorization seams and server routes for setup-pending
  Domain creation, invitation issuance/revocation, acceptance, and approval.
- Added invite-only account registration and a safe resolver/Copy Link UI.
  Raw tokens are returned only to the issuer's redirect flow and are never
  persisted or logged.
- Closed direct Domain and request writes; sanctioned services use explicit
  override access and transaction propagation.
