# P08X-T02 — Schema foundation: type tree, template selection, lifecycle stages, locked split

Status: complete

## What shipped

- **New collection `type-folders`** — navigation-only folders for the Document
  Type tree (domain required, optional department, name, self-parent,
  systemManaged). Access closed; beforeChange enforces same-Domain parent and
  department plus an ancestor-walk cycle guard.
- **Document Types gain** `department` (subdomain rel), `typeFolder`
  (type-folders rel), and `templateSelection` (blank|markdown|form, default
  blank). Same-Domain hooks for department/typeFolder. The legacy `allow*`
  flags stay physically in place; the inspector (T04) will drive them from
  `templateSelection` (the `/api/document-types` route already accepts the
  selection and derives the flags).
- **New collection `lifecycle-stages`** — one row per (Document Type, stage):
  enabled, allowOnCreation, folder, privateDraftsAllowed, and the four role
  lists (read/write/editOthers/manage, hasMany roles). Unique (documentType,
  stage) at the DB + index level; same-Domain folder/role hooks.
- **Lifecycle vocabulary + locked split:**
  - `Lifecycle` is exactly `draft | submitted | filed | deprecated`;
  - `locked` is a separate boolean (default false) meaning only "not
    editable" — `canEditDocumentBody(state, locked)` is unlocked AND
    Draft/Filed;
  - supersession preserves the stage and applies the preservation lock as a
    boolean; `priorLocked` replaces `priorLifecycle` on the relationship row
    and correction restores exactly that prior flag;
  - `typeRouting`: `submitted` maps the legacy pendingReviewFolder field,
    `deprecated` maps lockedFolder;
  - provenance gains the `deprecated` event (contract list 21 → 22);
  - workflow `lock`/`unlock` toggle the boolean on any stage and never move
    stages; deprecate/restore operations land with T07.
- **`privateDraft`** checkbox on Documents (default true; enforcement is T06).
- **`lifecycleStages.ts`** helper: the four stage constants, labels, the
  idempotent default-row seed (Filed enabled; Draft enabled + allowOnCreation +
  privateDraftsAllowed; the rest disabled) used by T04 create and seeds, and
  row loaders.
- **Migration** `src/scripts/migrateP08XDocumentTypes.ts` +
  `migrate:p08x-document-types` npm script (idempotent, additive, no data
  backfill). **Applied to the dev DB** (sl-civic-archive.db) — columns/tables
  verified present. Payload types regenerated.
- Seeds rewritten for the new vocabulary/fields (index, phase7Acceptance,
  p07xIntegrated); old development databases are abandoned, not migrated.
