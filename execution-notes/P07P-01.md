# P07P-01 — Baseline instrumentation and semantic oracle

Status: complete in the current working tree (2026-09-04).

The isolated benchmark runner is `npm run bench:p7p -- --scale small|large`.
It creates a uniquely named temporary SQLite database, refuses the working
database, reports session-load, pure-decision, read-scope, version-parent, and
navigation timings, and never prints document bodies or credentials. The
small run completed on this machine with 3 Domains, 60 Folders, and 120
Documents: session load 3.2 ms, 1,000 pure decisions 0.3 ms, read-scope 0.1
ms, version-parent query 6.3 ms, and navigation decisions 0.2 ms. The runner
now closes the database handle before attempting disposable-directory cleanup;
Windows may retain a temporary directory briefly if the adapter process still
owns a WAL handle.

The pure evaluator tests are the semantic oracle. They cover Character/User
precedence, deep Folder specificity, Role inheritance, explicit denies,
strict active-Character validation, and malformed/cross-Domain resources.

The optional `src/lib/authz/diag.ts` helper remains disabled unless
`LOREFORGE_DIAG` is set; it records counts and timings only and excludes
private query values. Production/customer UI does not enable diagnostics.
