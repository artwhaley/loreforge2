# P08X-T06 — Lifecycle-stage authorization and private drafts

**Commit:** `P08X-T06 enforce lifecycle-stage permissions and private drafts`

## What was built

### Stage role lists feed authorization (`src/lib/authz/`)
- **`session.ts`**: the session now loads per-Type per-stage role lists
  (`lifecycle-stages` joined through the Domain's Document Types, one extra
  scoped query) into `session.stageLists`. New decision pieces:
  - `stageListDecision` — spec §3.4 merge rule: `readRoles` → `read`,
    `writeRoles` → `create_document` at that stage + `edit_document` on own,
    `editOthersRoles` → `edit_document` on any, `manageRoles` → transitions
    INTO that stage (the workflow seam passes the DESTINATION stage).
  - `privateDraftGate` — a `privateDraft` document is visible/editable only
    through its creator **Character** (never the broader User account, so a
    user's other characters are denied), with platform/domain administration
    bypass; even a direct read grant cannot open a private draft.
  - `stageManageGrant`, `stageReadablePairs`, `canCreateAtStage` — the
    transition/creation-phase seams shared with T07.
  - `decideRecordDocument` order: private-draft gate → narrowing denies →
    Type/Document grant → stage-list grant → default deny. Explicit denies
    still beat everything; stage lists refine, never replace, the evaluator.
- **`evaluate.ts`**: the Document branch resolves the deciding stage
  (`ref.stage ?? document.lifecycle`) and threads the row's
  `privateDraft`/`creatorCharacter` into the target.
- **`readScope.ts` / `folderProjection.ts`**: record-list predicates share a
  `stageReadablePairs`-driven predicate (stage-list read OR Type grant, minus
  private-draft rows the actor didn't create); `records` page and the
  `records-search` API use it, so lists match decisions.
- **`workflow.ts` / `documentAccess.ts`**: stage transitions check
  manage(destination) and a stage move out of Draft clears the private flag
  (a public Document cannot stay secretly private).

### Private-draft creation seams
- `Documents` gains `creatorCharacter` (set from the acting Character at
  creation in `archive.ts` / `generateDocument.ts`); `privateDraft` now
  defaults **true** with a legacy-corpus backfill in the migration script
  (pre-P08X documents were all public under the old model — the backfill is
  keyed on the new column's presence, so it runs exactly once).
- `creation.ts` plan gains `privateDraftsAllowed` from the Draft stage row —
  the T07 creation screen uses it to decide whether the private option is
  offered.

### Effective-access explanation
- Stage-list grants carry `stageGrant` (`roleName`, `stage`, `list`) on the
  decision; reasons read "Allowed by Scribe role on the Draft stage." The
  People view renders the decision reason, so the source of a grant is
  visible without new UI.

### Session-cache invalidation (`authzEpoch.ts` + `sessionCache.ts`)
- New `domains.authzEpoch` field; `bumpAuthzEpoch` increments it (plus a
  same-process bump map) on every lifecycle-stages write at the app seam —
  `applyLifecycleStageConfig` and `deleteTypeAction`. The React `cache()`
  session memo is keyed on the epoch, so a session loaded before a stage-list
  edit can never be reused after it, even within the same request; fresh
  requests always read the stored epoch.
- **Note:** the epoch bump lives at the app seam, not in a LifecycleStages
  collection hook — the original hook's nested `payload.update` on domains
  collided with the create transaction (`SQLITE_BUSY`), breaking sequential
  stage-row creation. The inspector server action is the only mutation path
  (access closed on the collection), so the seam covers every write.

## Tests (`src/lib/authz/stagePermissions.test.ts`, 9/9 green)

1. A role on the stage `readRoles` reads at that stage without any Type rule.
2. `writeRoles` creates at that stage and edits own documents only.
3. `editOthersRoles` edits others' documents at that stage only.
4. `manageRoles` authorizes transitions INTO that stage; denied without.
5. An explicit deny narrows a stage-list grant.
6. Private drafts: creator-only visibility — not other characters, not
   granted readers; domain administration sees all.
7. A stage move out of Draft clears the private flag; transitions honor
   manage(destination).
8. `privateDraftsAllowed=false` removes the private option from the creation
   plan.
9. Lifecycle-stages writes bump the Domain authorization epoch.
