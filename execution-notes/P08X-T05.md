# P08X-T05 — Duplicate semantics and template preservation

**Commit:** `P08X-T05 duplicate Document Types with independent template copies`

## What was built

### `duplicateDocumentType` (`src/lib/documents/typeDuplicate.ts`)
The core duplicate logic as a plain lib function (thin server action wraps it):
- Copies the Type row in its current state — **active stays active** — with
  name + ` (copyN)` (first free N in the Domain, `(copy1)` then `(copy2)`…).
- Deep-copies every **constructed child template of both kinds** (Markdown
  document + Form) as independent rows: name + ` (copyN)`, same title/body/
  header/footer/schema content, `active: true`, `version: +1`, never a shared
  reference. Base-template relations that stay inside the Type are rewired to
  the copied rows (two-pass: create with null base, then update) so the copy
  set is fully self-contained; external bases are dropped rather than shared.
- Copies the **lifecycle-stages rows wholesale**: enabled flags,
  allowOnCreation, stage folders, and all four role
  lists. (P08REG-01 later removed the privateDraftsAllowed flag this
  ticket carried.)
- Carries over `templateSelection` (+ derived allow\* flags), description,
  department/typeFolder placement, and filing policies.

### `duplicateTypeAction` (`src/lib/actions/documentTypes.ts`)
Thin audited wrapper — `manage_types_tags` at Domain, same-Domain lookup,
`revalidatePath`, readable error passthrough (`invalid` / `not-found`).

### UI
- **Right-click menu** (TypeTree): new **Duplicate** entry with hovertext,
  directly under Set active/inactive.
- **Inspector** (TypeInspector): new **Duplicate Type** secondary button in
  edit mode's save bar; after duplicating, the copy is selected in the tree
  (via the new `onDuplicate` prop on DocumentTypesBrowser).

## Tests (`src/lib/documents/typeDuplicate.test.ts`, 6/6 green)

The suite is run-idempotent: type names are stamped with `Date.now()` so
leftover rows from an earlier run against the same SQLite file never shift the
copy counter. Tests:

1. Duplicate adds `(copy1)` to the Type name and every constructed template
   name; the copy's template id differs from the original's.
2. The copy carries its own stage configuration wholesale (enabled, creation
   flags, private drafts, folders, and all four role lists match per stage).
3. Deep-copy independence — editing the copy's form leaves the original
   byte-identical, and editing the original leaves the copy untouched.
4. **The magic-pops-up scenario**: Form type with a form → switch to Markdown
   (form persists in the background) → duplicate → the copy has the markdown
   selection, its own markdown template, and the hidden form → switch the copy
   to Form → the copied form pops up named ` (copy1)` with the copy's own
   stage config; the original is untouched by the copy's switch.
5. Blank hides but never deletes constructed templates; switching back
   restores the exact prior template.
6. A second duplicate gets `(copy2)`; duplicating a foreign-Domain Type is
   refused (`not-found`).
