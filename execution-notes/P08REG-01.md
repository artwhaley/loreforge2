# P08REG-01 — Document Type inspector compaction + private drafts always allowed

**Owner decisions (end-to-end empty-domain test session):**

1. The inspector's Placement section (Department + Subfolder under its own
   heading) is gone — the two fields slid up into the identity section. The
   section heading and the "Which Department this Type belongs to…"
   explanation text are removed; per-field hovertext stays.
2. The Lifecycle section lost its "Each row is one stage…" paragraph and every
   per-row stage description. The table is now a true grid: one header row
   (Stage / On creation / Folder / Read / Write / Edit others / Manage) and
   one compact line per stage. Role cells keep the chip editor; rows grow
   only when permission lists wrap.
3. **Private drafts are always allowed.** The per-Type Draft-row
   `privateDraftsAllowed` control is removed everywhere — inspector,
   collection field, session facts, creation plan, duplicate path, and tests.
   The create screen's private/public choice remains for Draft-stage
   creations (default private); other initial stages still create public
   records.
