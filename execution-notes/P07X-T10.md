# P07X-T10 — Source-specific Work queues

Status: complete

## What shipped

- Added a platform Work projection for pending bootstrap and Character-merge
  items only. Domain join, claim, and document work never crosses into that
  queue.
- Added a Domain Work projection scoped to the selected acting identity. A
  matching Domain Administrator sees join/claim decisions; ordinary Characters
  see only pending Documents they can approve through the normal Type-aware
  authorization evaluator.
- Added Work entry points and approval links to the platform dashboard and
  Domain shell. Work is a projection of canonical request/document records,
  not a second generic queue model.
