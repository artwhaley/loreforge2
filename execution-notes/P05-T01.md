## Contract note (added by P05R-T00, CC-2026-09-03-04/05 context) — "new unlinked Character" semantics

A Character created by name during Concerns/Prepared-by filing is globally active, has **no controlling User** and **no Domain membership**; filing neither claims nor memberships the Character. Claiming/linking it later is a separate flow (Character claim/merge phases). Provenance and Concerns links must never be read as implying membership or control. No code change accompanies this note; it pins the contract so later Character phases do not misread the P05 records.
