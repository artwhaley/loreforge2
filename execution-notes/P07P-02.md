# P07P-02 — Request-scoped facts and pure batch evaluator

Status: complete (2026-09-04).

`src/lib/authz/session.ts` loads the authority, validated acting
User/Character/Domain tuple, Domain Roles, active assignments, active rules,
Folder ancestry metadata, and Departments once. All `find` calls explicitly
use unbounded pagination for authorization inputs. `sessionCache.ts` uses
primitive React `cache()` keys so independently constructed actor objects share
one request-local session; no session or decision survives a request.

TenantShell, People, Roles, Folders, Domain home, and Records use pure session
decisions for navigation and row controls. The legacy dead helpers
`loadCachedRoleTree` and `canManageAtAnyFolder` were removed. Senior Roles
inherit subordinate Role defaults; delegation remains strict-descendant,
same-Department only. Folder permissions remain independent from Role
assignment.

Verification: typecheck clean; normal regression suite 114 passing; isolated
Phase 7 authorization suite covers workspace admission, delegation, scoped
Folder controls, golden Role matrix, ownership/platform boundaries, and
strict Character identity.
