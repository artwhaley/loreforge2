# P07X-T03 — Document Type as primary record-permission resource (two-axis decision)

**Branch:** `phase-07x-acting-identity-document-workflows`

## What changed

Record authorization is now a **two-axis decision** — Document Type grants carry
ordinary record capability, Folder rules only narrow (deny) it, and direct
Document rules stay the exceptional most-specific same-record path.

**Engine (`src/lib/authz/session.ts`)**
- `PermissionRule` resource vocabulary gains `DocumentType` (capabilities.ts `RESOURCE_TYPES` + `RECORD_CAPABILITIES`; PermissionRules.ts collection relation/validation; rules.ts authoring helper).
- `decideInSession` dispatches Document targets with record capabilities to the new `decideRecordDocument` two-axis path and `DocumentType` targets to `decideDocumentTypeTarget` (create-before-exists). Folder/Subdomain/Domain targets keep the legacy linear decision (manage_folders/manage_access etc.).
- Semantics: Type grant = normal source; direct Document rule wins when present; Folder/Subdomain/Domain **grants never create a missing record capability**; effective Folder/ancestor **deny narrows any Type/Document grant**; no Type/Document grant = deny even when the Folder is visible. Principal precedence and Role-hierarchy direction preserved.
- Effective explanations report `Allowed by Warrior role on Incident Report.` / `Denied by Folder restriction on Sealed Investigations.` (session now carries role/folder names + `typeNames`).
- New pure helpers `grantedTypeIds` / `folderNarrowingDeny`; `resolveDocumentTarget` and `decideManyInSession` thread `documentTypeId`.

**Wiring**
- `evaluate.ts`: Document lookups pass `documentType`; new `DocumentType` branch verifies the Type belongs to the evaluated Domain (cross-Domain rejection).
- `documentAccess.ts`: `canAccessDocument` uses the two-axis per-record decision (no more folder-baseline scope); `readableVersionParentQuery` gets the type-aware clause.
- `readScope.ts`: scope shape is now `readableTypeIds` / `denyFolderIds` / `grantDocumentIds` / `denyDocumentIds` / `visibleFolderIds`; list queries (records page, domain home, records-search) filter by effective Type/Document authorization.
- Create preflights evaluate `create_document` against the chosen Document Type: archive.ts editor create, forms.ts filing, records/new template chooser, records page supersede capability.
- Acceptance seed mirrors record-capability Folder grants onto the Domain's Plain Text Type (the deterministic translation); Folder denies stay Folder-scoped to narrow Type grants.
- `src/scripts/migrateP07XTypeRules.ts` — dry-run report + deterministic `apply` translation of single-Type-Folder record grants; ambiguous/empty-Folder grants and narrowing denies are reported, never guessed. Verified both modes against a scratch DB.
