## Result

Added the shared sanctioned asset URL helper and same-Design validation. Design config refs now accept `/media/...` uploads and `/design-assets/<same-key>/...` bundled defaults, while rejecting remote/traversal/cross-Design bundled refs. Discovery now recursively materializes every `src/designs/<key>/assets/**` file into `public/design-assets/<key>/**`, strips only the source `assets/` directory from the public URL, preserves bytes, removes stale generated Design directories, rejects symlink escapes, and has a check mode that compares exact generated bytes. The four source thumbnails and Obsidian atmosphere are now authoritative inside Design folders.

Obsidian's pristine default is `/design-assets/obsidian/atmosphere.png`; its thumbnail, font files, and all catalog thumbnails use generated `/design-assets/<key>/...` URLs. Site Studio `/media/...` override semantics remain available and no upload path writes into a Design folder.

## Deviations / pressure

The packet's source layout and generated layout imply that `assets/` is a source-only container. The materializer therefore emits `/design-assets/<key>/<file>`, not `/design-assets/<key>/assets/<file>`, and the manifest/catalog conversion makes that explicit.
