# P07X-T04 — Type-permission UX and permission-aware Folder projection

Status: complete (`<commit>`)

## What shipped

- **Role × Document Type capability grid** (`TypePermissionGrid.tsx`) as the
  primary Role permission surface on `/domain/[slug]/roles`, driven by the
  T03 `PermissionAxis` rows (read/create/edit/delete/submit/approve +
  Advanced lifecycle/admin capabilities). Folder access moved behind an
  "Advanced" section in `RoleManager`.
- **Permission-rules route** now authors `DocumentType` resources for
  Character and Role principals (one JSON `capabilityStates` map per Type
  row), while the legacy Folder path (three-state read/write + Role default
  scope) stays intact. Fixed the pre-existing guard that rejected Role
  principals for non-Folder resources.
- **Permission-aware Folder projection** (`src/lib/authz/folderProjection.ts`):
  folders associated with readable routed Types/Documents, ancestor paths,
  explicit Folder grants, denied branches hidden, counts only over
  authorized Documents; matching domain_admin sees the whole Domain.
- **Records page/explorer** wired to the server-side projection counts.
- **People effective-access page** gains a Type-access summary for the
  subject Character.

## T02 fallout fixed along the way (P05R security suites)

T02 removed ambient User-level authority; the P05R sanctioned-seam suites
called the guarded routes with a JWT but no acting identity, so every seam
failed closed headlessly. Fixes:

- New `src/lib/tenant/actingIdentity.ts` — routes resolve the acting
  Character from the request's own selector cookies (behavior-identical to
  the old `next/headers` reads in production, and testable headlessly).
- All seven routes that resolve an acting identity now use it:
  role-assignments, roles, permission-rules, folders, domain-memberships,
  people-search, records-search.
- `accessBoundary.test.ts`, `peopleWorkspace.test.ts`, `domainRemoval.test.ts`
  fixtures provision the owner's `domain_admin` identity (T01) and the
  harnesses send the selector cookies — matching the browser flow.
- New `P07X-T04` route round-trip test (Role × Type grid) added to
  peopleWorkspace.
