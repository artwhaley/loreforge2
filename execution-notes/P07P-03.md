# P07P-03 — Authorized read scope, predicates, and indexes

Status: complete for the implemented Payload/SQLite boundary (2026-09-04).

`readScope.ts` computes A/G/D using the same pure evaluator as individual
decisions. Folder baselines are evaluated in memory; only documents with an
actual Document-scope exception are fetched, in 400-ID exhaustive batches.
Opening one document therefore never scans the Domain corpus. Records and
version-parent queries apply Domain, soft-delete, Folder, exception, and type
predicates before projection.

`migrateP07PIndexes.ts` is additive and idempotent, with eleven composite
indexes covering memberships, assignments, Role/Folder topology, rules,
documents, relationships, contexts, and provenance. Run
`npm run migrate:p07p-indexes` only with a concrete local `DATABASE_URI`; it
never targets a remote or production URI.

The repository intentionally keeps the existing Payload adapter rather than
introducing RLS, a second ORM, or a public raw-SQL API. Large ID sets are
chunked at the application boundary where Payload `IN` predicates are used.

Read-only planner evidence from the real development database is recorded in
[`P07P-03-EXPLAIN.md`](P07P-03-EXPLAIN.md).
