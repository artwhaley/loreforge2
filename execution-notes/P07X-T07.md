# P07X-T07 — Form Studio WYSIWYG Markdown header/footer

Status: complete

## What shipped

- Added optional `headerMarkdown` and `footerMarkdown` fields to Form Templates.
  The save hook canonicalizes LF newlines and rejects answer tokens in framing,
  so fixed framing cannot create structural Character links.
- Added a Form Studio framing editor with the existing safe Archive Markdown
  WYSIWYG toolbar plus a lossless Source (advanced) textarea. The input remains
  neutral `formSchema`; no HTML editor or second layout model was introduced.
- The shared neutral generation seam now composes nonblank header, generated
  question output, and nonblank footer with canonical blank-line boundaries.
  Empty framing preserves the prior output exactly, and the existing Markdown
  renderer keeps raw HTML inert.
- Form fill and Type-first New Document paths pass the framing fields through
  the same generation service. Existing legacy templates remain compatible.
