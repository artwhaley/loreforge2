**Commit:** PENDING (filled by the commit immediately after this note)

Implemented parent-Document authorization for version detail and version-list requests. Version detail resolves the Payload version ID to its parent before applying the existing Domain/document decision. Version lists return a parent constraint over readable Documents; unauthorized and soft-deleted parents are excluded without exposing foreign totals or bodies.

The regression now uses Payload's real endpoints: `GET /api/documents/versions` and `GET /api/documents/versions/:id`, plus Local API `findVersions` and `findVersionByID`. It includes a deliberate version-ID/document-ID collision. The previous `/api/documents/{id}/versions` assertion was removed because that is not the version-detail endpoint in this Payload version.
