## Result

Added a build-time manifest scanner that reads only immediate installable Design folders, ignores the existing generic `src/designs/shared` host-support folder explicitly, validates manifests without executing entrypoints, rejects traversal/symlink escapes, sorts keys deterministically, and writes `designKeys.ts` atomically. `--check`, configurable Design/output roots, and a Node test are included. `predev` and `prebuild` now run discovery automatically.

The generated key source is currently `civic`, `ledger`, `obsidian`, `poster` in lexical order. `types.ts` re-exports the generated `DesignKey`, `DESIGN_KEYS`, and `isDesignKey`; the registry/catalog still remain hand-maintained until P1-T03.
