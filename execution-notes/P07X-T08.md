# P07X-T08 — Secure invitation link foundation

Status: complete

## What shipped

- Added one access-closed `Invitations` collection with the three strict
  purposes (`domain_bootstrap`, `character_claim`, `domain_join`) and the
  issuer, target, expiry, revocation, usage, and last-used fields required by
  the corrective contract.
- Issuance generates 32 random bytes as a URL-safe token, stores only its
  SHA-256 digest, and returns the raw token once for the issuer's Copy Link
  flow. Safe projections and list views never include the digest or raw token.
- Purpose/Domain/Character state is validated on issuance and again inside a
  `BEGIN IMMEDIATE` transaction during consumption. Expired, revoked,
  exhausted, stale, or wrong-purpose links fail closed; competing one-use
  consumers have one winner.
- Added the safe `/invite/[token]` resolver and preserved an invite token
  through the existing sign-in/create-account links without introducing email
  delivery or magic-login semantics.
- Added the non-destructive SQLite migration for the Invitations table and
  allowed explicit ownerless `setup-pending` Community Domains, which is the
  state required by the bootstrap purpose.
